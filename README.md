# UNLIVED — พิพิธภัณฑ์อนาคตที่ไม่เคยเกิดขึ้น

เกมจำลองโลกภาษาไทย: **ถ้าความทรงจำเป็นเงิน ความฝันก่อสร้างเมือง และต้นไม้ลงคะแนนได้ สังคมจะเปลี่ยนไปอย่างไร?**

เลือกกฎโลก ปล่อยให้ประวัติศาสตร์เดินหน้า แทรกแซงทิศทาง แตกเส้นเวลาเพื่อทดลองอีกทาง แล้วจัดพิพิธภัณฑ์จากวัตถุที่ค้นพบ

## เปิดเล่น

**ใหม่ใน 1.2 — Private beta:** ล็อกอิน แยกโลกตามบัญชี จำกัดคำขอ พร้อม Docker + HTTPS proxy และเครื่องมือสำรอง/กู้คืน ดู [คู่มือ deploy](docs/DEPLOYMENT.md) โหมด `npm start` เดิมยังเปิดเฉพาะเครื่องตัวเองโดยไม่ต้องล็อกอิน

ต้องมี **Node.js 24 ขึ้นไป** ไม่ต้องติดตั้งแพ็กเกจ ไม่ต้องใช้ API key และเล่นแบบออฟไลน์ได้

Windows: ดับเบิลคลิก `start.bat` หรือรันคำสั่งในโฟลเดอร์โปรเจกต์:

```sh
npm start
```

เปิด **http://127.0.0.1:4317** ในเบราว์เซอร์ ปิดเซิร์ฟเวอร์ด้วย Ctrl+C
หากพอร์ตถูกใช้งาน ใน PowerShell ตั้ง `$env:PORT = '4318'` ก่อนรัน แล้วเปิดพอร์ตนั้นแทน

## ฟีเจอร์ที่ทำงานแล้ว

**ใหม่ใน 1.1 — ผู้คนในโลก:** ตัวแทน 8 สายงาน มีอาชีพ ความต้องการ สายสัมพันธ์ บันทึกชีวิต และผู้สืบทอด การตัดสินใจรายปีส่งผลต่อเมือง กดติดตามและเทียบคนเดิมในโลกที่แตกแขนงได้ วัตถุใหม่ระบุผู้ส่งมอบและเปิดอ่านชีวิตต่อได้

โลกเดิมเริ่มทะเบียนจากปีปัจจุบัน ไม่สร้างอดีตย้อนหลัง เมื่อต้องการเทียบชีวิต ให้แตกเส้นเวลาใหม่หลังอัปเดต เพราะโลกที่แตกไปก่อนมีทะเบียนคนถือว่าเริ่มบันทึกแยกกัน

- สร้างหลายโลกด้วยชื่อ เมล็ดกำเนิด และกฎ 1–3 ข้อจาก 8 กฎ
- จำลอง 1 หรือ 10 ปีต่อครั้ง; API รองรับ 1–50 ปี สูงสุด 2,000 ปีต่อโลก
- ดูเสถียรภาพ ความพิศวง ความเข้าใจ ระบบนิเวศ ความรู้ เสรีภาพ และประชากร
- ประวัติศาสตร์ กราฟ เหตุการณ์ วิกฤต และการแทรกแซง 4 แบบ
- แตกเส้นเวลาโดยเก็บอดีตเดิม แล้วเปลี่ยนกฎเพื่อเทียบโลกคู่ขนาน
- สะสมวัตถุ เขียนบันทึก เลือกจัดแสดง ค้นหา และกรอง
- บันทึก SQLite อัตโนมัติ และส่งออกโลกเป็น JSON
- หน้าจอภาษาไทย รองรับจอเล็กและคีย์บอร์ด

ลองใช้ “ความทรงจำคือสกุลเงิน” + “ความฝันก่อสร้างเมือง” จำลอง 10 ปี แตกเส้นเวลาโดยเปลี่ยนกฎหนึ่งข้อ แล้วจำลองทั้งคู่ถึงปี 20 เพื่อเปรียบเทียบ

ระบบใช้กฎและแม่แบบเรื่องเล่า ไม่ได้ใช้ AI หรือทำนายสังคมจริง ชื่อวัตถุซ้ำได้ แต่มีปีและเหตุการณ์ต้นกำเนิดต่างกัน

## โครงสร้าง

```text
server.js              HTTP server และ API
src/catalog.js         กฎ เหตุการณ์ นโยบาย
src/engine.js          ตัวจำลอง deterministic และการแตกเส้นเวลา
src/people.js          ชีวิต ความต้องการ การตัดสินใจ และผู้สืบทอด
src/store.js           SQLite repository
public/                หน้าจอ กราฟ วัตถุ และ stylesheet
public/people-ui.js     ทะเบียนผู้คน บันทึกชีวิต และเทียบชีวิตคู่ขนาน
tests/                 ทดสอบ engine, API และ persistence
docs/ARCHITECTURE.md   กลไกและขอบเขตการออกแบบ
docs/ROADMAP.md        แผนพัฒนาต่อระยะยาว
data/museum.sqlite    สร้างอัตโนมัติเมื่อเปิดโปรแกรม
```

## ตรวจสอบ

```sh
npm run check
npm test
```

ใช้ test runner ของ Node การทดสอบ API ใช้ฐานข้อมูลชั่วคราวแยกจากข้อมูลจริง

## สำรองข้อมูล

หยุดเซิร์ฟเวอร์ก่อนแล้วคัดลอกโฟลเดอร์ `data` ทั้งโฟลเดอร์ กู้คืนด้วยการวางกลับขณะเซิร์ฟเวอร์ปิด ปุ่มส่งออก JSON ใช้เก็บหรือวิเคราะห์โลกหนึ่งใบ **รุ่นนี้ยังไม่มีการนำเข้า JSON**

โหมด local ฟังเฉพาะ `127.0.0.1` ส่วนโหมด private beta มีบัญชีและแยกข้อมูลผู้ใช้ตามคู่มือ deploy ยังไม่มี cloud sync ข้ามเซิร์ฟเวอร์

## เพิ่มเนื้อหา

เพิ่มรายการใน `src/catalog.js` ตามรูปแบบที่มีอยู่ ข้อความเหตุการณ์ใช้ `{motif}` แทนหัวข้อกฎ หากเพิ่มกฎใหม่ ให้เพิ่มรูปวัตถุใน `artifactArt()` ของ `public/app.js` ด้วย

การเปลี่ยนสูตรหรือเนื้อหาอาจทำให้ seed เดิมได้อนาคตต่างจากรุ่นก่อน บันทึกเวอร์ชันโปรแกรมไว้คู่กับไฟล์ส่งออกเมื่อต้องการทดลองซ้ำ
