# แผนโปรเจกต์ระยะยาว

รายการต่อไปนี้คือ **งานอนาคตที่ยังไม่ได้สร้าง** รุ่นปัจจุบันเล่นได้ตั้งแต่กำเนิดโลกถึงจัดพิพิธภัณฑ์

## ระยะ 2 — ชีวิตรายบุคคล

เพิ่มตัวละคร อาชีพ ความต้องการ ความสัมพันธ์ และความทรงจำ ให้เหตุการณ์เกิดจากการตัดสินใจของคน ทำ provenance และครอบครัวข้ามรุ่น

เกณฑ์สำเร็จ: ติดตามผลกฎโลกต่อชีวิตคนหนึ่งคนได้ตั้งแต่ต้นจนจบ

## ระยะ 3 — ภูมิศาสตร์ความคิด

แผนที่ hex มีเขต ทรัพยากร เส้นทาง ย่านเงาอิสระ โรงไฟฟ้าความเงียบ และธนาคารความทรงจำ พร้อมการอพยพและนโยบายรายพื้นที่

เกณฑ์สำเร็จ: นโยบายจุดหนึ่งส่งผลต่อพื้นที่ข้างเคียงอย่างตรวจสอบได้

## ระยะ 4 — ภาษาสร้างกฎ

JSON schema สำหรับกฎและเหตุการณ์ มีเงื่อนไข ผลลัพธ์ น้ำหนัก validation และ versioning ติดตั้งเนื้อหาโดยไม่รันโค้ดที่ไม่เชื่อถือ

เกณฑ์สำเร็จ: สร้าง content pack 10 เหตุการณ์โดยไม่แก้ engine

## ระยะ 5 — ห้องทดลองเหตุและผล

Rewind จาก checkpoint, append-only event log, branch graph, batch simulation, worker thread และ normalize ฐานข้อมูล

เกณฑ์สำเร็จ: ทดลอง 100 seed ต่อชุดกฎโดยไม่บล็อก UI

## ระยะ 6 — ส่งต่อพิพิธภัณฑ์

Import/export พร้อม schema validation, ZIP backup, จัดตำแหน่งวัตถุ และส่งออกนิทรรศการ HTML อ่านอย่างเดียว

เกณฑ์สำเร็จ: ย้ายพิพิธภัณฑ์ไปอีกเครื่องและตรวจความครบข้อมูลได้

## ระยะ 7 — หลายผู้เล่น

ออกแบบบัญชี สิทธิ์ concurrency ฐานข้อมูลหลายผู้ใช้ การสำรอง rate limiting และการป้องกัน CSRF/DNS rebinding ก่อนเปิดสาธารณะ แยกจากโหมด local

AI narrator เป็นส่วนเสริมได้ โดยแยกข้อความตกแต่งออกจากผลคำนวณ เพื่อรักษาการทำซ้ำและไม่ต้องพึ่งบริการภายนอก
